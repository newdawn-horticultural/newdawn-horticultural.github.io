# New Dawn ブログ

園芸療法と幸福学をめぐる、実践と研究の記録。
New Dawn公式サイトの既存5記事を引き継いだブログです。

- 公式ホームページ：https://www.newdawn-horticultural.com/
- 公開予定URL：https://newdawn-horticultural.github.io/

## 初回の公開設定

リポジトリの **Settings → Pages** を開き、以下を設定します。

|項目|設定|
|---|---|
|Source|Deploy from a branch|
|Branch|main|
|フォルダ|/docs|

**Save** を押すと、保存済みの`docs/`がブログとして公開されます。
反映には時間がかかる場合があります。公開の状態はGitHubのPages設定やActionsで確認できます。

## 記事の更新

`posts/`のMarkdownが編集用の原稿、`docs/`が公開用のHTMLです。
原稿を変更した後は、Python 3.10以上で次のコマンドを実行して公開用ファイルを更新し、変更した原稿と`docs/`をGitHubへ保存します。追加ライブラリは不要です。

```bash
python3 build.py --site-url https://engeishokubutu365-crypto.github.io/new-dawn-blog
python3 verify.py
```

先頭の`---`の間にあるJSONは記事情報、次の`---`以降は本文です。
新しい記事では`date`、`slug`、`title`、`category`、`description`を設定します。
`category`は`activity`・`research`・`column`のいずれかです。
著者名が不明な場合は`author`を空欄にします。`slug`には小文字英数字とハイフンを使用し、公開後は変更しないことを推奨します。

本文では見出し（`##`・`###`）、段落、箇条書き、太字、Webリンク、写真を使えます。
写真を`assets/images/`へ保存し、本文に`![写真の説明](assets/images/photo.jpg)`と記載します。

独自の投稿編集画面と、原稿からの自動再生成はこの初期版には含まれていません。
チャットで修正を依頼する場合は、原稿と公開用ファイルを一緒に更新できます。

本文は2026-10-12に公開サイトから取得しました。`source-extracts.txt`に取得時のテキスト、`migration-map.json`に旧記事と新しいパスの対応を残しています。

画像ファイルは`assets/images/`と公開用の`docs/assets/images/`に保存しており、旧サイトが削除されても写真の表示に依存しません。
旧サイトが配信するサイズ違いの画像から、最大1600ピクセル幅の既存画像を選んで保存しています。元の掲載時のトリミングを保持し、追加の画像加工は行っていません。
`photo-migration.json`に取得元URL・掲載位置・サイズを記録しています。学会記事のGoogle Drive資料リンクの閲覧は未確認です。
記事紹介文とカテゴリは、今回の表示用に追加した情報です。本文の表現は原文を引き継いでいます。
原文中の「自分らしく」という因子名、誤字や重複する文章などは、移行時に勝手に変更していません。

現在のホームページからのリンク切替、旧記事の移転案内・転送、独自ドメイン設定は別途行います。
